# Spectral-PN phonon BTE solver

Code, deterministic reference solvers, and archived training runs for the
manuscript

> M. Herkaliuk and A. Gilchuk, *A data-free spectral-P_N neural solver for
> the transient phonon Boltzmann transport equation across the
> ballistic-to-diffusive crossover* (submitted to the Journal of
> Computational Physics).

## What this is

A physics-informed neural solver for the transient phonon Boltzmann
transport equation (BTE) under the relaxation-time approximation, applied to
the transient thermal grating (TTG) in silicon.  The solution is represented
exactly in space (Fourier harmonics) and in angle (Legendre / P_N expansion
up to a truncation order), so only the time dependence of the per-mode
expansion coefficients is learned.  Per-mode asymptotic enrichments -- the
exact collisionless (Duhamel) part of the transport generator and the
Chapman-Enskog slaved flux, composed through a UGKS-form resolvent kernel at
a self-consistent collective rate -- remove the representational degeneracy
that makes conventional sampled-residual PINNs collapse or freeze on this
problem.  Training is **data-free**: the loss is the equation residual plus
exact initial/boundary structure; no reference solution enters the
objective.  The trained solver recovers the grating decay rate across nine
grating periods spanning the ballistic-to-diffusive crossover
(L = 0.01-100 um), in one and two dimensions, to a worst decay-rate error of
0.58% against a deterministic discrete-ordinates (DOM) reference and, on
the absolute axis, reproduces bulk silicon's thermal conductivity
(kappa = 142.3 W/(m K) at the production mode set, inside the experimental
142-156 band).  The mode set is the branch-resolved silicon dispersion with
Holland relaxation times on a midpoint k-grid whose outer radius closes the
three-acoustic-modes-per-primitive-cell sum rule (`physics/ttg_dispersion.py:
sum_rule_grid`), plus one lumped Einstein reservoir for the optical branches;
its heat capacity is 1.003 of the tabulated rho c_p with nothing fitted.  A
deterministic matrix-exponential study of the same model quantifies what a
frozen-tau propagator misses on a finite-amplitude asymmetric drive
(Appendix B of the manuscript); no trained nonlinear solver is reported.

The repository carries the paper's full evidence:

- `pinn_bte/` -- the solver package: coefficient networks and residuals
  (`models/spectral_pn.py`), the training harness
  (`training/transient/spectral_pn_trainer.py`), the silicon phonon model
  (`physics/mesh_1d.py`, `physics/ttg_dispersion.py`,
  `physics/optical_reservoir.py`, `physics/comb_routing.py` -- the one place
  the active mode set is resolved from `data/ladders.yaml`,
  `physics/fullbz_modes.py`), the spectral DOM reference solver
  (`physics/ttg_dom.py`), the gray-BTE Volterra reference
  (`physics/gray_ttg.py`), the deterministic matrix-exponential P_N solvers
  of the nonlinear propagator-miss study (`physics/ttg_pn2q.py`,
  `physics/ttg_pnhq.py`), and the decay-rate estimator conventions
  (`physics/decay_metrics.py`).  Plus the sampled-residual control trainers
  the failure sweep uses (`training/transient/nongray/`, `gray/`).
- `experiments/` -- the runners: `run_spectral_pn.py` (the solver),
  `run_1d.py` (the mode-resolved sampled-residual MLP control),
  `run_gray_ttg_control.py` (the gray-BTE control).
- `data/` -- the archived runs behind every figure and table
  (`data/figures_registry.yaml` maps each figure/table entry to its runs;
  `data/ladders.yaml` is the machine-read pin of the active ladder), the
  derived artifacts, and the re-score ledgers.
- `scripts/` -- the figure generators, the DOM-vs-Volterra validation, the
  deterministic propagator-miss study, the optical-reservoir disclosure, and
  the scoring paths (`scripts/score_run.py` for any archived arm,
  `scripts/score_sumrule_ladder.py` / `scripts/score_sumrule_adoption.py`
  for the adoption evidence of the production mode set against its
  predecessor generation).
- `figures/` -- the manuscript's figures as generated by the scripts above.
- `tests/` -- the contract tests: solver/residual identities, 1D = 2D
  parity, mode-set capacity contract (the dimensional axis), estimator
  conventions, reference-window replay, the mode-set routing, and the
  burned-value figure guard.

The training data are generated programmatically from the silicon phonon
dispersion and relaxation-time model; there are no external datasets.

## Install

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

All commands below are CPU-only unless a GPU is requested with
`--device cuda`.

## Regenerate the figures

Each generator writes `figures/<name>.{pdf,png}` and refuses to write on a
failed internal check (layout, mode-set guard, bit-exact reproduction gate):

```bash
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_schematic.py               # fig1_schematic
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_figures.py                 # fig2_regime_map, fig3_traces, fig_reduced_formulations
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_repin_figures.py           # figB_repin_banded_rates
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_mode_spectrum_figure.py    # fig_mode_spectrum
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_absolute_ladder_figure.py  # fig_absolute_ladder
CUDA_VISIBLE_DEVICES="" uv run python scripts/make_identifiability_figure.py  # fig_identifiability
```

The absolute-observable artifact behind `fig_absolute_ladder` can itself be
regenerated (31 multi-axis checks; exits non-zero on any failure):

```bash
CUDA_VISIBLE_DEVICES="" uv run python scripts/pn_absolute_ladder.py --write
```

## Re-score a run

Any archived linear run directory scores to the printed decay-rate ratio
with one command (|A| estimator, same-window DOM-reference denominator):

```bash
uv run python scripts/score_run.py data/runs/pn_sumrule_ladder_1d/ladder_L1.0_1d
uv run python scripts/score_run.py data/runs/gray_ttg_control/A1_primary_retry_k8
uv run python scripts/score_run.py data/runs/mlp_control/1d_nongray_large_dt_1.0um_100K/20260707_085244
```

The multi-axis shape battery over the full 18-arm ladder (bit-exact
reproduction gate + shape/rate/terminal readings):

```bash
uv run python scripts/pn_shape_battery.py
```

The production mode set's adoption evidence -- the 18-arm ladder scored
against its predecessor generation (`data/runs/pn_corridor_ladder_60k`) and
the seed / control batteries -- is re-scored by:

```bash
CUDA_VISIBLE_DEVICES="" uv run python scripts/score_sumrule_ladder.py
CUDA_VISIBLE_DEVICES="" uv run python scripts/score_sumrule_adoption.py
```

The optical-reservoir disclosure (`data/optical_reservoir_disclosure.txt`)
is regenerated by `scripts/optical_reservoir_disclosure.py`.  The dt->0
propagator-miss report of Appendix B (`data/c22_sumrule_repin_report.json`;
the predecessor mode set's `data/c22_joint_repin_report.json` is kept for
comparison) is the product of `scripts/pn_expm_miss_converged.py --job
report` over its 413-rung campaign, which is not archived here; single rungs
are reproducible with `--job rung`.

## Train

One arm of the production ladder (the corridor-gauge configuration; ~3 GPU
hours at 60k epochs, or pass a small `--epochs` for a CPU smoke run):

```bash
uv run python experiments/transient/run_spectral_pn.py --L 1.0 \
    --formulation xihybrid --blend ugks --gauge corridor \
    --epochs 60000 --snapshot-selection final --mode-source joint-sumrule \
    --seed 42 --device cuda
```

`--mode-source joint-sumrule` is the production mode set; `joint` is its
predecessor (same physics on the zone-edge endpoint grid) and `shipped` the
acoustic-only historical set -- the archived arms record which one they were
trained on, and the scorers refuse to mix them.

The sampled-residual controls: `experiments/transient/run_1d.py --mode
nongray_large_dt ...` (mode-resolved MLP control) and
`experiments/transient/run_gray_ttg_control.py --xi 0.6 ...` (gray-BTE
control); the archived arms' exact command lines are recorded in
`data/figures_registry.yaml` and in the per-campaign `arms.tsv` manifests.
